# 灌溉控制器固件 · 使用文档

ESP8266（NodeMCU）双路水阀灌溉控制器固件的公开发布仓库：这里提供**固件下载（Releases）**与设备**远程自动升级（OTA）**的分发服务。设备固件经本仓库审核发布，设备通过 HTTPS 加密通道安全获取更新，**升级不会丢失 Wi-Fi / MQTT 等全部配置**。

## 一、快速上手（3 分钟）

1. **接线**：两路继电器模块分别接 NodeMCU 的 `D1`（浇水阀）与 `D2`（冲洗阀），继电器模块**独立 5V 供电并与开发板共地**。首次通电先**不接水路**，确认页面操作能听到继电器"咔哒"声、且到时自动断开，再接水管。
2. **上电配网**（见下一节）。
3. 手机浏览器打开设备页面即可控制。

## 二、配网（让设备连上家里 Wi-Fi）

**首次上电**设备会自动广播配置热点：

- 热点名：`Irrigation-Setup`（无密码，信道 6）
- 手机连接该热点后，浏览器自动弹出配置页；若没有弹出，手动访问：`http://192.168.4.1/`
- 在页面里：**扫描 → 点选自家 Wi-Fi → 输入密码 → 保存**。设备自动重启入网，页面上会显示设备新 IP。

**以后想换 Wi-Fi / 改密码**，四种方式任选：

| 方式 | 操作 |
|---|---|
| A. 同网直改（最方便） | 手机和设备还在同一 Wi-Fi 下 → 浏览器打开 `http://设备IP/setup.html` → 重新扫描保存 |
| B. 一键开热点 | 设备页面「设置 → 远程/配网」点“开配网热点”，手机即可连 `Irrigation-Setup` 配网 |
| C. 自动兜底 | 设备连不上旧 Wi-Fi（改了密码/换了路由器）约 2.5 分钟后**自动重新打开热点** |
| D. 断电重启 | 若存的凭据已失效，等同 C |

> 配错不会变砖：设备只保存最后一次成功配置，任何情况下断电重启等待 3 分钟即可回到方式 C 的热点状态。

## 三、控制页面（手机浏览器，无需 APP）

配网成功后，同一 Wi-Fi 下访问 `http://设备IP/`（或 `http://irrigation.local`）：

- **操控页**：浇水阀 / 冲洗阀 卡片，显示 通水中(倒计时) / 已关闭，一键开关，底部红色 **“⛔ 全部阀门紧急关闭”**。
- **设置页**：Wi-Fi 状态与重新配网入口、MQTT 远程配置、固件更新（见第五节）。
- 任何页面打不开时，先访问 `http://设备IP/ping`：返回 `pong irrigation-c <版本号>` 即设备正常。

**定时浇水**：设备内置每日计划（默认 07:30 浇水 45 秒），联网对时后自动生效；修改请联系厂商或按随机说明卡操作。

## 四、巴法云（微信小程序远程控制）

出门在外想用手机小程序开关水阀？设备原生支持免费的巴法云（bemfa.com）：

1. 注册 [巴法云控制台](https://cloud.bemfa.com)，进入 **MQTT 设备云**，新建两个**开关**类型主题（名称必须完全一致）：
   - `irrwater006` —— 浇水阀
   - `irrflush006` —— 冲洗阀
2. 设备「设置页 → MQTT」：
   - 协议模式选 **巴法云**（服务器/端口自动填 `bemfa.com : 9501`）
   - 账号栏填入控制页面的**用户私钥**（32 位，密码留空）
   - 主题前缀填 `irr` → 勾选“启用”，**保存即生效**
3. 微信搜索小程序「巴法智能家居」登录同一账号，即出现两个开关：
   - 开 = 按默认时长通水，到时**自动断水**（受安全上限约束）
   - 关 = 立即断水
   - 页面/定时/小程序任一处操作，其余端状态自动同步。

> 说明：设备也可对接自建 MQTT 服务器（协议模式选“标准 MQTT”）。巴法云免费额度对家庭场景足够。

## 五、固件更新（OTA，免拆机）

设备具备**安全远程升级**：

- 入口：设置页 → “远程更新” → **检查更新** → 有新版本时点 **升级到 v×.×.×**。
- 过程：设备会自动**重启一两次**，每次约 30~60 秒（检查/下载在独立的安全升级模式中进行），期间页面暂时打不开属正常。
- 保障：
  - **Wi-Fi、巴法云/ MQTT、定时计划等所有配置完整保留**（配置存于独立存储区，升级不触碰）；
  - 下载失败自动回退，不会变砖；
  - 新版本若有问题无法启动，设备**自动回滚到上一个版本**；
  - 阀门安全逻辑在升级全过程仍然生效（绝对时限断电保护）。
- 提示：升级全程请保持设备供电；勿在通水作业中途升级。

本仓库 [Releases](../../releases) 同步存档每个版本的固件文件（`firmware-vX.Y.Z.bin`），供厂商刷机与查验。

## 六、安全机制（为什么敢让它自动浇水）

| 层 | 行为 |
|---|---|
| 单次时长硬上限 | 浇水阀 ≤ **180 秒**、冲洗阀 ≤ **30 秒**，任何入口（页面/小程序/定时）超发一律收敛 |
| 绝对断水时刻 | 开阀即锁定断水时间点，页面崩溃/断网不影响 |
| 独立巡检 | 每 200ms 检查所有阀门，越界**强制断水** |
| 失效自愈 | 巡检一旦停摆：先断电所有阀门，再安全重启 |
| 继电器校验 | 周期性回读引脚核对物理状态，触点粘连会持续告警重试 |

水塔/水桶建议：接水前把出水口先离开容器做“空跑”验证一次开→自动关全流程。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 页面显示“设备离线” | 手机与设备是否同一 Wi-Fi；试 `http://设备IP/ping`；换 8080 端口试试 `http://设备IP:8080/` |
| 换了路由器 Wi-Fi 后失联 | 等 3 分钟自动出热点 `Irrigation-Setup`，重配一次即可（第二节） |
| 巴法小程序一直“离线” | ① 确认主题名 `irrwater006/irrflush006` 一字不差；② 确认端口 9501（不是 1883）；③ 私钥是否复制完整；④ 设备重启一次 |
| 检查更新提示“DNS 仍返回 fake-IP” | 家里存在透明代理/旁路由的 DNS 模式问题：把代理设备改为 redir-host（真实 IP）模式，或联系厂商 |
| 升级后 App 显示旧版本 | 正常需等确认窗 60 秒；刷新即可 |
| 继电器咔哒但不通水 | 检查独立 5V 供电与共地；核对触发方式（高/低电平）设置 |
